# llm-hallucination-detection
-Work in Progress- We fine-tuned a DeBERTa model, using data from SQuAD, to detect hallucinations in other LLMs by comparing a generated answer against the inputted question and evidence. We compare the accuracy of answers generated by Phi-3 Mini, Llama 3.1 8B Instruct and Mistral 7B Instruct.
